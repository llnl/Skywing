Skywing
=======

**Skywing** is a platform for collaborative autonomy where decentralized agents collaborate
to solve problems. It provides tools to build distributed, asynchronous and resilient algorithms.

* **Lightweight**: Designed for settings with limited computation, memory and communication
* **High reliability**: Designed for unreliable environments with changing device participation
* **Decentralized architecture**: Assumes no shared memory and arbitrary device connection patterns
* **Built-in Algorithms**: Includes processors for distributed optimization, linear solvers, and consensus

See more in :doc:`docs/package_overview`
