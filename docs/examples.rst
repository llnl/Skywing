Examples
========

This section documents the example implementations that demonstrate how to use Skywing
for various distributed algorithms.

The examples are located in the ``python/examples`` directory. These scripts
are not installed as Python modules, but you can run them directly from the command line.

See the tutorials section for detailed walkthroughs of how to use these examples.

Example Scripts
---------------

The following example scripts are available:

* ``2iters.py``: Example showing how to run two iterations simultaneously
* ``pyjob.py``: Example showing a custom job
* ``simple_iteration.py``: A driver script for running iterations with various processors

Running Examples
----------------

Examples can be run directly from the command line. See the :doc:`tutorials` section for detailed instructions.
